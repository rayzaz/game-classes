# v42.8.1

- Добавлена вкладка `Старые пароли` в закрытый Google-реестр доступов.
- В архив автоматически внесены все 22 старые записи из переданного файла паролей.
- Добавлена пакетная миграция старых `PORTAL_USERS_JSON*` в Google без смены исходных паролей.
- Добавлена кнопка `🔐 Синхронизировать доступы` в админском реестре анкет.
- Синхронизация автоматически выдаёт логины/пароли уже опубликованным анкетам, у которых доступа ещё нет.
- Пакетное создание не меняет пароли существующих аккаунтов при повторном запуске.
- Старые перенесённые аккаунты теперь можно сбрасывать через админку.
- Для старых аккаунтов сохранён fallback на Netlify ENV, если Google-сервис временно недоступен.
