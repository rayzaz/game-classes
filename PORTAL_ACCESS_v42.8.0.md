# v42.8.0 — автоматические логины и пароли после публикации анкеты

## Что изменено

После успешного создания кандидата из одобренной анкеты система автоматически:

1. использует `characterId` как логин игрока;
2. генерирует случайный 8-значный пароль;
3. считает `scrypt`-hash и случайный salt на стороне Netlify;
4. создаёт отдельный закрытый Google Spreadsheet `[🔐] Черный клевер — ДОСТУПЫ`, если его ещё нет;
5. сохраняет в нём имя, characterId, логин, читаемый пароль, salt/hash и служебные даты;
6. возвращает логин и пароль администратору сразу после публикации;
7. позволяет позже снова посмотреть доступ и сбросить пароль из карточки публикации.

ID созданного реестра сохраняется в Script Properties Apps Script под ключом:

`PORTAL_ACCESS_SPREADSHEET_ID`

Создавать Google-файл вручную не нужно.

## Старые игроки

Существующие пользователи из `PORTAL_USERS_JSON`, `PORTAL_USERS_JSON_1` и `PORTAL_USERS_JSON_2` продолжают работать без изменений.

Новые аккаунты создаются в Google-реестре. При входе сервер сначала ищет старый аккаунт в Netlify ENV, а если его нет — проверяет новый Google-реестр.

Поэтому миграция старых аккаунтов не обязательна для запуска v42.8.0.

## Важно про пароль

По просьбе администратора текущий пароль сохраняется в читаемом виде в отдельной закрытой Google-таблице, чтобы его можно было восстановить и передать игроку. Для самой проверки входа используется не открытый пароль, а `scrypt` hash.

Если доступ к таблице `[🔐] Черный клевер — ДОСТУПЫ` получит посторонний человек, он увидит пароли игроков. Не открывайте общий доступ к этому файлу.
