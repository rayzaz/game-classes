# Установка v42.8.0 — анкеты без донора + автоматические логины и пароли

Обновление состоит из двух частей: GitHub-проект сайта и Google Apps Script. Нужно обновить обе.

## 1. GitHub-проект

Распакуй архив поверх `C:\game-classes`:

```powershell
Expand-Archive `
  "$HOME\Downloads\game-classes-access-v42.8.0.zip" `
  -DestinationPath "C:\game-classes" `
  -Force

cd C:\game-classes
```

Проверка:

```powershell
npm ci
npx tsc --noEmit
npm run build
```

Публикация через GitHub:

```powershell
git status
git add .
git commit -m "Add automatic player logins and passwords"
git push origin main
```

Если Netlify связан с GitHub, он сам задеплоит новый commit. `netlify deploy --prod` не нужен.

## 2. Google Apps Script

Открой Apps Script, который используется в `CHARACTER_SERVICE_URL`.

Файл для полной замены:

`CharacterService_DONORLESS_ACCESS_v42.8.0.gs`

В редакторе Apps Script:

1. открой основной файл с Character Service;
2. `Ctrl+A`;
3. удали старый код;
4. вставь весь `CharacterService_DONORLESS_ACCESS_v42.8.0.gs`;
5. сохрани;
6. **Deploy → Manage deployments → Edit → New version → Deploy**.

Если обновляешь существующий deployment, URL `CHARACTER_SERVICE_URL` остаётся тем же.

## 3. Как теперь выдаётся доступ

После успешной публикации новой анкеты:

- `characterId` становится логином;
- создаётся случайный 8-значный пароль;
- Apps Script автоматически создаёт отдельный закрытый Google-файл `[🔐] Черный клевер — ДОСТУПЫ`;
- логин и пароль показываются в админке;
- там же есть кнопки `Показать логин и пароль`, `Копировать` и `Сбросить пароль`;
- игрок сразу может войти в кабинет этим логином и паролем.

Создавать Google-файл с паролями вручную не требуется.

## 4. Старые аккаунты

Старые пользователи из `PORTAL_USERS_JSON*` продолжают работать как раньше. Новый реестр используется для автоматически созданных аккаунтов.

Файл `пароли.docx` можно оставить как старый архив, но новые аккаунты туда вручную добавлять больше не нужно.

## 5. Первая проверка

После публикации обеих частей создай тестовую одобренную анкету и опубликуй кандидата.

Нормальный результат:

- кандидат создаётся в Google;
- в админке появляется блок `🔑 Доступ игрока в кабинет`;
- логин равен `characterId`;
- показан 8-значный пароль;
- ссылка `Открыть закрытый Google-реестр доступов` открывает созданный файл;
- вход игрока работает;
- после перезагрузки админки кнопка `Показать логин и пароль` снова получает его из закрытого реестра;
- `Сбросить пароль` выдаёт новый пароль, а старый перестаёт работать.
