# v42.8.1 — единый Google-реестр старых и новых логинов/паролей

## Что изменено

После обновления закрытый Google Spreadsheet `[🔐] Черный клевер — ДОСТУПЫ` содержит две вкладки:

- `Пользователи` — рабочие аккаунты портала: characterId, имя, логин, читаемый пароль, salt/hash и служебные поля;
- `Старые пароли` — полный архив старых логинов и паролей из переданного администратором файла.

Старые пароли больше не остаются только в Word-файле. При синхронизации старые игроки из `PORTAL_USERS_JSON*` переносятся в рабочую вкладку `Пользователи` с теми же логинами и исходными паролями.

## Уже опубликованные персонажи без доступа

В разделе админки `Анкеты персонажей` появилась кнопка:

`🔐 Синхронизировать доступы`

Она:

1. создаёт/обновляет закрытый Google-реестр;
2. переносит старые аккаунты из `PORTAL_USERS_JSON*` в Google, сохраняя старые пароли;
3. находит уже опубликованные анкеты;
4. для опубликованных персонажей без аккаунта автоматически создаёт логин и новый 8-значный пароль;
5. показывает созданные логины/пароли прямо в админке;
6. сохраняет их в Google-реестр.

Кнопку можно нажимать повторно: существующие аккаунты не пересоздаются и пароли не меняются.

## Новые публикации

После успешной публикации новой анкеты доступ по-прежнему выдаётся автоматически:

- логин = `characterId`;
- пароль = случайное 8-значное число;
- проверка входа использует `scrypt` salt/hash;
- читаемый пароль хранится в закрытом Google-реестре для администратора.

## Старые игроки и сброс пароля

После миграции старого игрока Google-запись становится приоритетной для его пароля, даже если старый `PORTAL_USERS_JSON*` ещё остаётся в Netlify. Поэтому кнопка `Сбросить пароль` теперь работает и для перенесённых старых игроков.

Если Google-сервис временно недоступен, старый игрок всё равно может войти через существующую запись в Netlify ENV как запасной вариант.

## Важно

Файл `[🔐] Черный клевер — ДОСТУПЫ` содержит пароли в читаемом виде по требованию администратора. Не открывайте к нему общий доступ и не публикуйте его ID/содержимое.
