# v42.7 — создание анкет без донора того же класса

- Убрана обязательная зависимость создания от существующего персонажа того же класса.
- Сервер сначала предпочитает шаблон того же класса, но при его отсутствии использует любой активный рабочий Spreadsheet как технический каркас.
- Для всех 19 классов добавлена явная привязка к колонкам `Классы!E:W` из загруженной СИСТЕМЫ.
- План создания повышен до версии 3 и передаёт `templateMode`, `targetClassId`, `classFormulaProfile`.
- Админка больше не блокирует dry-run из-за несовпадения класса технического шаблона.
- В журнале и интерфейсе «донор» переименован по смыслу в «технический шаблон».
- При ошибке старого Google writer в универсальном режиме выводится явная подсказка про патч Apps Script.

## Проверки

- `tsc --noEmit` — пройдено.
- `node --check` для изменённых Netlify `.mjs` — пройдено.
- `git diff --check` — пройдено.
- Полный Vite build в Linux-контейнере не выполнен, потому что загруженный `node_modules` содержит Windows-набор optional dependencies Rollup и не содержит `@rollup/rollup-linux-x64-gnu`. Это проблема переносимости приложенного `node_modules`, а не TypeScript/синтаксиса патча.

## Важно

Внешний Google Apps Script (`CHARACTER_SERVICE_URL`) не находится в загруженном проекте. Для реального создания нового класса без одно-классового донора writer тоже должен перестать проверять класс шаблона и применять классовые формулы из центрального листа `Классы`. Инструкция лежит в `GOOGLE_APPS_SCRIPT_CLASS_TEMPLATE_PATCH.md`.
