# v42.7.2

Исправлена оставшаяся серверная зависимость от класса технического шаблона.

- Google Apps Script больше не должен сравнивать `Лист персонажа!E38` шаблона с классом новой анкеты.
- Класс новой личной таблицы назначается после `makeCopy`.
- Классовые формулы новой личной таблицы берутся из `[🕸] Черный клевер СИСТЕМА → Классы`.
- Источник: нужная колонка `E:W`, строки `3:15`.
- Назначение: новая личная таблица `ТЕХ!E3:E15`.
- Символ класса в `Основная → Маги` больше не наследуется от технического шаблона.
- План GitHub-проекта дополнительно передаёт `sourceRows: 3:15` и `personalFormulaRange: ТЕХ!E3:E15`.
- Публикация проекта рассчитана на GitHub → Netlify, без `netlify deploy --prod`.
